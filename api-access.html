Quick Start Example
import requests

# Get latest signals
response = requests.get(
    'https://api.tradepilot.io/v1/signals',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

signals = response.json()
for signal in signals['data']:
    print(f"{signal['symbol']}: {signal['action']} at {signal['price']}")

Getting Started

Base URL

All API requests should be made to:

https://api.tradepilot.io/v1/
Requirements
  • Valid API key (obtain from dashboard)
  • HTTPS requests only
  • JSON request/response format
  • Rate limiting compliance

Authentication

API Key Authentication

Include your API key in the Authorization header:

curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://api.tradepilot.io/v1/signals

API Endpoints

GET /signals

Retrieve latest trading signals

Parameters
Parameter Type Description Default
limit integer Number of signals to return (1-100) 20
symbol string Filter by trading pair (e.g., BTCUSDT) all
status string Filter by status (active, closed, cancelled) all

WebSocket Feeds

Real-Time Signal Feed

Connect to real-time signal updates via WebSocket

wss://ws.tradepilot.io/signals 
const ws = new WebSocket('wss://ws.tradepilot.io/signals');

// Authentication
ws.onopen = function() {
  ws.send(JSON.stringify({
    action: 'authenticate',
    token: 'YOUR_API_KEY'
  }));
};

// Handle incoming signals
ws.onmessage = function(event) {
  const signal = JSON.parse(event.data);
  console.log('New signal:', signal);
};

// Subscribe to specific symbols
ws.send(JSON.stringify({
  action: 'subscribe',
  symbols: ['BTCUSDT', 'ETHUSDT']
}));
